# Alexander Gaskins

Academic website: https://alexandergaskins.github.io/

Home, Awards, Publications, Presentations, Software, Teaching, Extension, and Contact.

This is a static GitHub Pages website. Publish the main branch from the repository root. No build step or dependencies are required.

Edit each HTML page directly. Shared styling is in style.css, navigation and media behavior in site.js, and media in assets/. CV.pdf contains the supplied curriculum vitae.

The Home playlist and FuelDeep3D media files contain no audio tracks. The presentation recording is hosted on YouTube and includes audio.
